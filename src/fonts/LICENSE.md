# 内嵌字体来源与许可

本项目把下列开源字体按界面实际用字裁剪为 woff2 子集后内嵌使用，运行时不联网加载，也不依赖访客系统字体。

| 文件 | 字体 | 上游 | 许可 |
|---|---|---|---|
| `msz-0-0.woff2` … `msz-3-0.woff2` | Ma Shan Zheng（马善政毛笔楷书） | Google Fonts / https://fonts.google.com/specimen/Ma+Shan+Zheng | SIL Open Font License 1.1 |
| `zcool-0-0.woff2` … `zcool-3-0.woff2` | ZCOOL XiaoWei（站酷小薇） | Google Fonts / https://fonts.google.com/specimen/ZCOOL+XiaoWei | SIL Open Font License 1.1 |

## 许可要点

两套字体均以 SIL Open Font License 1.1 发布，允许自由使用、研究、修改与再分发（包括嵌入到软件中）。
经修改的版本不得单独以原字体名称发布；字体本身不得单独售卖。
完整许可文本见 <https://openfontlicense.org/open-font-license-official-text/>，
以及各上游仓库中的 `OFL.txt`。

本项目对字体所做的唯一改动是：按界面实际用字裁剪字符子集，并转换为 woff2 格式。
字体版权归原作者与 Google Fonts 项目所有。
